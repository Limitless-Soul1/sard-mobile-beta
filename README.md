# سَرْد للجوال (نسخة تجريبية)

قارئ كتب EPUB وPDF لأجهزة أندرويد، بُني للعربية أولاً. مكتبتك تبقى على جهازك.

**[تحميل آخر نسخة تجريبية](https://github.com/Limitless-Soul1/sard-mobile-beta/releases)**

هذه نسخة تجريبية (Beta): قد تظهر فيها أخطاء أو يتغير سلوكها بين نسخة وأخرى، فاحتفظ بنسخة من كتبك الأصلية.

## التثبيت

1. افتح صفحة النسخ أعلاه وحمّل ملف `.apk` من قسم Assets.
2. افتح الملف من الجوال، واسمح بالتثبيت من هذا المصدر إذا طلب أندرويد ذلك.
3. اضغط «تثبيت».

يحتاج التطبيق إلى أندرويد 7 أو أحدث.

قد يعرض Google Play Protect تنبيهاً لأن التطبيق من خارج المتجر ولم يره من قبل. اختر «Scan app» ليفحصه، أو «More details» لبقية الخيارات.

## التحديث

عند فتح التطبيق يبحث عن نسخة أحدث في الخلفية، وإذا وجدها يعرضها عليك. يمكنك أيضاً البحث بنفسك من **الإعدادات ← حول ← التحقّق من التحديثات**. اضغط «تحديث الآن» ثم وافق على التثبيت، وتبقى مكتبتك كما هي.

## الإنترنت والخصوصية

الكتب والمكتبة تعمل دون إنترنت. يتصل التطبيق بالشبكة في حالتين:

- **البحث عن تحديث:** يسأل GitHub عن آخر نسخة، فيرى GitHub عنوان IP الخاص بك.
- **القراءة الصوتية:** تستخدم أصوات Microsoft Edge، فيُرسل نص ما تستمع إليه إلى تلك الخدمة.

## المشاكل والملاحظات

افتح [مشكلة جديدة](https://github.com/Limitless-Soul1/sard-mobile-beta/issues) واذكر نوع جوالك ونسخة أندرويد ورقم نسخة سرد، وهو ظاهر في **الإعدادات ← حول**.

# Sard Mobile (Beta)

An EPUB and PDF reader for Android, built for Arabic first. Your library stays on your device.

**[Download the latest beta](https://github.com/Limitless-Soul1/sard-mobile-beta/releases)**

This is a beta: expect bugs and changes between versions, and keep your own copies of your books.

## Install

1. Open the releases page above and download the `.apk` file under Assets.
2. Open the file on your phone, and allow installs from this source if Android asks.
3. Tap Install.

Requires Android 7 or later.

Google Play Protect may show a notice because the app comes from outside the store and it hasn't seen it before. Choose Scan app to have it checked, or More details for the other options.

## Updates

When it opens, the app looks for a newer version in the background and tells you if there is one. You can also look yourself under **Settings → About → Check for updates**. Tap Update now and confirm the install; your library stays as it is.

## Internet and privacy

Books and the library work offline. The app uses the network in two cases:

- **Looking for an update:** it asks GitHub for the latest version, so GitHub sees your IP address.
- **Read-aloud:** it uses the Microsoft Edge online voices, so the text you listen to is sent to that service.

## Problems and feedback

Please [open an issue](https://github.com/Limitless-Soul1/sard-mobile-beta/issues) with your phone model, Android version and the Sard version shown under **Settings → About**.
